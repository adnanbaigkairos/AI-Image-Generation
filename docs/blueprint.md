# **App Name**: PromptForge

## Core Features:

- Authentication System: User registration and login with secure password hashing and token-based sessions.
- Dark-Themed UI: A dark-themed user interface providing an optimal viewing experience.
- Prompt Input: Text input area for users to input vague prompts they want to see come to life in the form of vivid images.
- Prompt Enhancer: GPT-powered tool that transforms simple user inputs into detailed, cinematic prompts, guiding the image generation process.
- AI Image Generation: Generate stunning images from enhanced prompts using models. Customize images via settings for style and aspect ratio.
- Image Display & Management: View generated images and choose to download, share to social media, or save for later.
- Batch Image Generation: Allow users to generate 2-4 variations of images simultaneously, exploring slightly different results from the same enhanced prompt. Implement a toggle for enabling batch mode.

## Style Guidelines:

- Primary color: Saturated purple (#9D4EDD) to create a mystical and creative atmosphere.
- Background color: Dark grayish-purple (#24123F) to complement the primary color and set the dark theme.
- Accent color: Electric indigo (#623CEA) to create emphasis, particularly on interactive elements.
- Use clean and modern sans-serif fonts, optimizing for readability on dark backgrounds. Consider a font weight slightly heavier than regular to ensure clarity.
- Incorporate neon-style icons with glowing effects to match the app's futuristic theme.
- Employ a dashboard-style layout with clear sections for prompt input, image generation settings, and image display. Use a grid system for responsive design.
- Implement smooth, subtle animations for transitions and interactive elements, such as hover effects on image cards and loading animations during image generation.
